# Public content contract

This repository stores public Atlas Open Source knowledge only: Markdown/MDX, JSON/YAML, public assets, sources, glossary entries, technology and repository profiles, patterns, guides, and comparisons.

The Atlas renderer, validation logic, scoring, recommendation logic, automation, and website deployment are maintained separately in the private platform repository.

The canonical corpus remains under `src/content/` during Phase 1 to preserve history. Git and these plain-text files are authoritative; generated indexes and projections are disposable outputs.
