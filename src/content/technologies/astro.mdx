Astro is a static-first web framework suited to content-heavy public sites.

## Relevance

Astro fits this repository because it can publish Markdown/MDX content with very little client-side JavaScript while still allowing structured content collections and typed metadata.

## Agents-OS Mapping

Astro is not part of Core governance. It belongs to the reference/documentation surface: a public layer for evidence, comparison, and pattern extraction.
