The fastest way to learn AI technology is not to chase every new framework. It is to study repositories by category.

A useful first map includes agent runtimes, workflow orchestration, retrieval systems, coding agents, content infrastructure, and governance tools.

## Start With The Problem Category

If you want to build an AI assistant over documents, look at retrieval systems like Onyx and Khoj.

If you want coding automation, study OpenHands, SWE-agent-style systems, Jules-style execution, and developer tools such as Cline.

If you want workflows, study LangGraph, Mastra, and Temporal-style orchestration.

If you want content and SEO infrastructure, look at Astro, Keystatic, Mitosis, Hydrogen, and static documentation systems.

## What To Extract From Each Repo

For each repository, capture:

- What problem it solves.
- What abstractions it introduces.
- What it assumes about users.
- How it manages state.
- How it handles tools and permissions.
- Whether it produces evidence you can inspect.

That is the difference between collecting links and building knowledge.
