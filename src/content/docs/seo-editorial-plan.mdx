The target reader has intermediate technical knowledge and is beginning to evaluate AI infrastructure.

## Search Intent Clusters

| Cluster | Reader Intent | Example Content |
| --- | --- | --- |
| Learn AI infrastructure | Understand concepts | What is an AI agent runtime? |
| Compare tools | Choose between options | LangGraph vs Mastra vs OpenHands |
| Build first project | Follow a tutorial | Choosing your first agent framework |
| Understand repositories | Evaluate GitHub projects | What to look for in an AI repo |
| Adopt safely | Avoid risk | Governance, evidence, and approvals |

## Editorial Minimum

The first deploy should include:

- One homepage with a clear learning path.
- Two evergreen guides.
- One practical tutorial.
- One blog post explaining the map of the field.
- One repository catalog page.
- One glossary page with core terms.
- At least ten repository records.

## SEO Principles

- Use plain titles that match search language.
- Explain concepts before naming advanced abstractions.
- Link every technology to patterns and glossary terms.
- Prefer comparison tables and practical checklists.
- Keep internal links dense and natural.
