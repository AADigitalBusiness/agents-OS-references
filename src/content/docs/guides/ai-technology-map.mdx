Modern AI technology is easier to compare when grouped by purpose.

## Categories

| Category | What It Does | What To Look For |
| --- | --- | --- |
| Agent runtime | Runs tool-using AI loops | tool API, state, memory, observability |
| Orchestration | Coordinates steps and actors | graphs, retries, branching, scheduling |
| Retrieval | Finds relevant knowledge | indexing, chunking, ranking, citations |
| Software factory | Automates coding workflows | issues, patches, tests, reviews |
| Governance | Controls authority and risk | permissions, approvals, audit evidence |
| AI UI | Makes AI usable by humans | chat, admin panels, workflows, review |
| Content infrastructure | Publishes and manages knowledge | Markdown, CMS, docs, search, SEO |
| Developer tooling | Helps build and debug | local runtime, IDE, logs, traces |

## How To Use This Map

When evaluating a tool, place it in one primary category and one secondary category.

For example:

- OpenHands: software factory + agent runtime.
- LangGraph: orchestration + agent runtime.
- Khoj: retrieval + personal AI assistant.
- Keystatic: content infrastructure + Git-based CMS.
- NiceGUI: AI UI + Python frontend.

This avoids comparing tools that solve different problems.
