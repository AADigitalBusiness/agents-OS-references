Agents-OS References is a documentary knowledge base for analyzing technologies related to AI systems.

Use this site to collect evidence, compare tools, extract patterns, and decide what should be adopted, adapted, watched, or discarded for Agents-OS and related projects.

## Main Areas

- **Blog**: research notes and public essays.
- **Glossary**: stable language for concepts and terms.
- **Technologies**: reference profiles for tools, frameworks, platforms, and methods.
- **Repositories**: structured catalog of source repositories.
- **Patterns**: reusable technical and architectural patterns observed across references.

## Principle

This repository documents references. It does not define normative governance behavior. Normative semantics belong in `agents-os-core`.
